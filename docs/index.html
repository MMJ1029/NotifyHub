装到真我手机三步：
  1. 点上方按钮下载 notifyhub-v1.3.apk（手机浏览器可能提示"下载完成"）。
  2. 点通知栏里的下载文件，或在"文件管理"里找到它，点安装。已装过旧版会直接覆盖安装，不用卸载。
    真我会拦"未知来源"：弹窗点「设置」→ 允许该来源，或 设置 → 密码与安全 → 系统安全 → 安装未知应用 → 允许对应浏览器。
  3. 打开「通知汇」→ 开启通知访问权限（真我路径：设置 → 通知 → 更多通知设置 → 通知使用权）。
    ⚠️ 如果首页状态卡显示"服务没连上"：到 设置 → 通知 → 通知使用权，把「通知汇」关掉再打开一次，App 会自动重连。
  4. 首次打开若弹出「允许后台运行」，请点去允许；并到 手机管家 → 应用 → 通知汇 开启自启动（真我机锁屏杀后台，不然可能收不到新通知）。
  5. 点首页右上角 ＋（分类）：新建分类、把微信/QQ 等归到一起、选颜色/字体、开单独提醒；点设置改字体、开未读提醒、管理已屏蔽的群/好友。
